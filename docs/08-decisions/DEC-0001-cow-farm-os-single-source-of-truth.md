# DEC-0001 — COW Farm OS as Single Source of Truth

**Status:** Accepted  
**Date:** 2026-08-14

## Context

The dairy-farm project will generate research, financial assumptions, design ideas, breeding plans, supplier information and operating decisions over a long period. Keeping these only in chat would make future verification and continuity difficult.

## Decision

Use the GitHub repository `kamlesh840k-arch/cow-farm-os` as the canonical project knowledge base and decision record.

## Consequences

- Important research should be summarized into the repository.
- Sources should be recorded where possible.
- Major choices should receive numbered decision records.
- Financial assumptions must be distinguishable from verified facts.
- Future models, designs and operating documents should refer back to the repository.

## Review trigger

Review this structure if the repository becomes difficult to navigate or the project needs a dedicated database/application layer.
